# Checklist de qualidade — SpecKit Specify
Revisado em 2026-09-28.

- [x] Escopo e valor definidos.
- [x] PCC e ADR identificados sem atribuir mapeamento detalhado ao PCC.
- [x] Histórias priorizadas e verificáveis independentemente.
- [x] Requisitos testáveis sem marcadores de esclarecimento.
- [x] Critérios mensuráveis.
- [x] NULL distinto de zero.
- [x] Limites temporais e conflitos explícitos.
- [x] Revisão humana distinta do processamento automático.
- [x] Dependências e limites registrados.
- [x] Falhas, integridade e continuidade cobertas.
